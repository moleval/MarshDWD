## Что это за проект

AutoLISP-обработчик DWG для AutoCAD: пакетно правит слои/цвета/высоты текста и
вставляет блок «Марка этажа» с атрибутом «Этаж». Работает через ActiveX/ObjectDBX
(файлы не открываются в редакторе).

```
dist/MARSHDWG.lsp   рабочий файл для AutoCAD: CP1251 + CRLF, НЕ пересохранять
                    в UTF-8 (28 128 б, 732 строки, Ред. 1.2)
src/MARSHDWG.lsp    исходник (UTF-8/LF) — правится он, затем python3 tools/build.py
tools/build.py      сборка dist из src
tests/structure.py  разбор LISP, арности, CP1251/CRLF, зеркало правил
tests/check_rules.py сверка правил с дампами реальных DWG (LibreDWG)
tests/test_lisp_logic.py таблицы «имя файла → Этаж», «марка → цвет» через
                     настоящий код из src (tools/lisp_sim.py — интерпретатор AutoLISP)
tests/test_names.py таблицы-контракты
tools/dryrun.py     сухой прогон на DXF (ezdxf) + tools/render.py — картинки
```

Команды в AutoCAD: `MARSHDWG` (папка), `MARSHDWGFILE` (один файл),
`MARSHDWGSRC` (источник блока), `MARSHDWGCFG` (показать правила).

## Действующие правила (ТЗ заказчика, уже реализованы)

1. Выключить слои: `A-ANNO-NOTE`, `A-AREA-IDEN`, `A-DETL`, `A-FLOR-IDEN`,
   `G-ANNO-NOTE`, `G-ANNO-REVC`, `G-ANNO-REVC-IDEN`, `G-ANNO-TEXT`, `I-FURN`,
   `P-SANR-FIXT`.
2. Цвет 251 слоям: `A-ANNO-DIMS`, `A-ANNO-DIMS-100`, `S-GRID`, `S-GRID-IDEN`.
3. Марки осей (слой `S-GRID-IDEN`, включая содержимое блоков) — красный.
4. Размеры: текст H=250, задний план «нет» (DIMTFILL=0, BackgroundFill=False).
5. Обозначения изделий — H=225.
6. Марки изделий и отметки — цвет, задний план не скрывать:
   EI — красный, двери `Д*` — синий, окна `ОК*`/`ББ*`/`Б*` — жёлтый,
   лоджии `ОЛ*` — голубой, витражи `ВТ*` — зелёный, отметки — фиолетовый 200.
   Если символ не подошёл — цвет по слою (A-GLAZ-IDEN жёлтый, A-DOOR-IDEN
   синий, A-WALL-IDEN зелёный).
7. Штриховки: цвет фона «Нет».
8. Блок «Марка этажа» с атрибутом «Этаж» вставляется в точку **0,0**, масштаб
   **1:1**; атрибут = часть имени файла после «ОП» (`Объект ОП1.dwg` → `1`).
   Нет «ОП» в имени — блок не вставляется.

Все правила собраны в конфиг-блоке в начале `src/MARSHDWG.lsp` (`*md:...*`).
Перед изменением файла делается копия в `MARSHDWG_BACKUP`, пишется
`MARSHDWG_LOG.txt`.

## Правила работы над кодом

- Правишь `src/MARSHDWG.lsp`, затем `python3 tools/build.py` (пересборка dist).
- Перед коммитом: `python3 tests/structure.py` и `python3 tests/test_lisp_logic.py`
  должны давать `ИТОГ: OK`; в CI (`.github/workflows/tests.yml`) то же самое.
- `dist/MARSHDWG.lsp` — CP1251 + CRLF без BOM. Не пересохранять в UTF-8.
- Правки — точечными заменами; после правки проверять, что число вхождений
  изменилось как ожидалось.
- В сообщениях коммита и в ответах: что менялось, какие тесты прошли.

## Чего в репозитории нет и почему

- Исходные DWG (объект заказчика) — в `.gitignore`, в публичный репозиторий не
  попадают. Для офлайн-проверок кладутся в `input/`, дампы — `python3
  tools/dwg_dump.py input/*.dwg` (нужен LibreDWG `dwgread`).
- Примеры в документации и тестах обезличены: вместо шифра объекта — `Объект `.
  Сохраняй это правило в новых примерах и тестах.
- `dump/`, `out/` — генерируемые артефакты, в git не идут.

## Технические заметки для тебя (не для вставки в чат)

### Где лежит LISP

| Что | Ссылка |
|---|---|
| Рабочий файл (CP1251) | https://github.com/moleval/MarshDWD/blob/main/dist/MARSHDWG.lsp |
| Скачать напрямую | https://raw.githubusercontent.com/moleval/MarshDWD/main/dist/MARSHDWG.lsp |

Приём для пользователя: `Invoke-WebRequest -Uri "<raw-ссылка>" -OutFile "$env:USERPROFILE\Downloads\MARSHDWG.lsp"`,
затем в AutoCAD `(load "C:/Users/molev/Downloads/MARSHDWG.lsp")`.

### Что сделать перед новым чатом, чтобы запись в репозиторий работала

1. Arena → подключённые приложения → **GitHub** → Configure/Manage repositories →
   добавить `moleval/MarshDWD` в список доступных, права **Contents: read & write**
   (для fine-grained token) или scope `repo` (классический).
2. В новом чате приложить/указать репозиторий `moleval/MarshDWD` и вставить текст
   выше.
3. Проверка в первом же ответе: агент должен уметь `git clone`/`push` в
   `moleval/MarshDWD`. В прошлой сессии токен видел репозиторий только на чтение
   (`git push` → `403 … denied`, `POST /git/commits` → `403 Resource not
   accessible by integration`), поэтому запись не работала.

### Если запись всё ещё недоступна

Тот же текст задания годится и для чата с репозиторием `moleval/Mark`; тогда
работаем в ветке и переносим файлы вручную (архив/`git bundle`), как это делалось
раньше. Лучше всё-таки выдать права на `MarshDWD` — тогда коммиты идут прямо туда.


## Ред. 1.2 — что изменилось после ревью 1.1

Версия 1.1 писалась в `moleval/Mark/dwg-auto` и перенесена сюда, в
`moleval/MarshDWD`, вместе с исправлениями по ревью (`docs/REVIEW-1.1.md`).

| Что | Было в 1.1 | В 1.2 |
|---|---|---|
| `md:collect` + `*md:recurse*` | обход затягивал `MARSHDWG_BACKUP` и перезаписывал резервные копии | папка бэкапа исключена из обхода |
| `md:hatch-bg` | при `BackgroundColor = nil` писал «изменено», счётчик рос | `nil` и `ColorMethod = 0` = «менять нечего» |
| `*md:require-backup*` | объявлен, но нигде не читался | `t` — без копии пропуск, `nil` — продолжать с предупреждением |
| `отметок` | `bump` без условия, счётчик не был идемпотентен | считается только по факту изменения |
| `размеров` в журнале | счётчик сменил смысл на «стили размеров» | строка журнала: `стилей размеров` |
| `md:scan-paperspace` | мог обойти модель дважды | модель отсекается и по имени `MODEL`, и по `TabOrder` |
| `md:do-layers` | `(/= nil 251)` — ошибка типа на недоступном цвете | `numberp` + `md:try` |
| `tests/structure.py` | счётчик символов (ломался бы на `\"`), без контракта на число defun, не ловил мёртвые `*md:*` | разбор дерева, `EXPECT_DEFUN = 53`, проверка «параметр читается» |
| Пути | `strcat folder "\\" name` | `strcat folder "/" name` — `vl-file-directory-p` понимает оба, но `/` не даёт съехать кавычкам |

Что осталось открытым (вопросы заказчику, не блокируют работу):
2400 или 250 для текста «Марка этажа»; `1` или `01` в атрибуте «Этаж»;
нужна ли рекурсия и листы по умолчанию (сейчас оба флага `nil`).

### Правила правки (важнее, чем всё остальное)

1. Править только `src/MARSHDWG.lsp` — `dist` собирается `tools/build.py`.
2. Правки — скриптом с `assert old in t`: не совпало — падение, файл не
   записан. Никаких правок скобок «на глаз».
3. После каждого смыслового блока: `python3 tools/build.py &&
   python3 tests/structure.py`. Ориентир — **53 defun** и `dist == src`.
4. `tests/structure.py` падает, если `defun` не 53, если хоть один `defun`
   не на верхнем уровне, если `*md:*` объявлен и не читается.
5. Перед работой: `git log --oneline -3 && git status` — песочница может
   откатить рабочее дерево, работать от `origin`.
