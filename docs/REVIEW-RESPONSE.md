## Принято и исправлено в коде

| № | Замечание | Что сделано |
|---|---|---|
| 4 | Выключение слоёв не должно быть «заморозкой» и не должно трогать `VP Freeze` | Только `LayerOn = :vlax-false`. Заморозка, `VP Freeze`, `Lock` не меняются. Если слой уже выключен — счётчик не растёт (файл не считается изменённым зря). В README добавлено: объекты внутри блоков на выключенном слое всё равно обрабатываются, это оставлено осознанно. |
| 6 | Листы (Layout) не обрабатываются | Добавлены параметр `*md:scan-paperspace*` (по умолчанию `nil` — только модель) и `md:scan-paperspace`. Включает обход блоков листов; `TabOrder = 0` (модель) пропускается, при недоступном `TabOrder` лист всё равно проверяется. |
| 12 | Счётчики врут: показывают «обработано», даже если ничего не изменилось | Все счётчики идемпотентны: `md:set-color`, `md:set-h`, `md:bg-off`, `md:do-grid`, `md:do-dim`, `md:do-layers`, штриховки увеличивают счётчик только при фактической смене значения. Повторный прогон даёт нули — это и есть признак «правила применены». |
| 13 | `BackgroundFill` сравнивается через `eq :vlax-true` — в разных версиях приходит `1`, `-1`, `0` | Введена `md:on-p` (`nil`/`:vlax-false`/`0` → nil; `:vlax-true`/число ≠ 0 → t). Через неё работают `md:bg-off` и проверка `LayerOn`. Маска снимается только когда она реально стоит. |
| 14 | Нет гарантии резервной копии | `*md:require-backup* = t`: если копию в `MARSHDWG_BACKUP` сделать не удалось, файл **пропускается** (`[ПРОПУСК] нет резервной копии`), не открывается и не сохраняется. |
| 11 | Параметр `*md:recurse*` объявлен, но не работал | Реализован `md:collect`: при `*md:recurse* = t` обход вложенных папок. По умолчанию `nil` — только выбранная папка. |
| — | Размеры: `Dimtfill` писался в стиль повторно каждый файл | Пишется только если значение стиля отличается; если стиль размера не найден — предупреждение в журнал. |

2. **п.2 — продукт и версия AutoCAD.** ObjectDBX и `vla-*` в **AutoCAD LT не работают**

   должен ещё и менять цвет) — уточнить.
